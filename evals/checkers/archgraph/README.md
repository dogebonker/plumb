# Native Archgraph layout proof

Run `bash evals/checkers/run.sh --only archgraph`. This needs Python 3.8+ and the immutable Cargo installation recorded in `kit/layouts/tools.yaml`; it installs no language dependencies. Missing/unverified tools exit 2 and print the pinned install line. `LAY01_ALLOW_SKIP=1` accepts a disclosed skip.

For a separately verified local build, set `ARCHGRAPH_BIN` and `ARCHGRAPH_SHA256`. The runner verifies that hash, records it with the source pin, and explicitly labels build provenance as supplied by the caller. Do not use an arbitrary same-version binary: Archgraph's version is still 0.1.0.

Each TS, Python and Go fixture contains a legal adapter-to-domain import; the planted file adds the reverse import. Native scans must succeed in both states, `check` must return 0 on clean and 1 on planted, and only the planted verdict must contain `domain-not-to-adapters` and the planted filename. Copied source trees are removed; scan/check logs and JSON evidence remain in the printed temporary directory. This proves import-rule enforcement, not full parser soundness or behavioral correctness. The source pin's native engine is experimental; cycle regressions require `diff --fail-on new-cycles` (plain `check` does not fail cycles).

All three clean/planted pairs passed. This hash identifies that build artifact, not a portable release checksum.
