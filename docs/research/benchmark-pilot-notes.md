# Benchmark pilot notes — 2026-10-12

The first six trials were a diagnostic run. They exposed controller and permission defects and cannot establish a fair Factory versus Superpowers ranking. The completed protocol pair below has separate pinned fixtures and runner provenance. Earlier correction attempts also remain diagnostic, rather than enlarging the comparison sample.

The diagnostic artifacts are retained at [the original report](/private/tmp/factory-comparison-pilot-20261012/report.md), [summary](/private/tmp/factory-comparison-pilot-20261012/summary.json), and [provenance](/private/tmp/factory-comparison-pilot-20261012/provenance.json). Tokens include input, output, cache reads, cache creation, and subagent usage from the last cumulative `result.modelUsage`. They are not unique source tokens or output tokens. Observed cumulative totals across resumed sessions must not be summed again. Factory's interrupted calls have unknown exact totals; the report's `>=` entries are lower bounds from the last recorded cumulative result. Unfinished source snapshots failed the trusted tests, but snapshot grading does not turn an interrupted workflow into a delivered result.

The last authorization and pagination Factory invocations each emitted a terminal root `state: question` result before their process exited. The controller was still waiting for process exit, so it did not deliver that question to the scripted operator and eventually timed out. The evidence is in [authorization turn 04](/private/tmp/factory-comparison-pilot-20261012/trials/document-authorization-factory-1/turn-04.jsonl) and [pagination turn 03](/private/tmp/factory-comparison-pilot-20261012/trials/document-pagination-factory-1/turn-03.jsonl). Those trajectories also record denied scratch-file Read/Write operations. Consequently the elapsed timeout is not evidence that Factory needed that long to return its next question.

The corrected controller monitors root terminal result events as they are written, then gracefully stops lingering handles. Forwarded subagent results do not end a root turn. A real-process regression test covers a process that prints a root result and then sleeps; another covers a child result followed by sleep. Claude scratch storage now lives under each trial's working directory through `CLAUDE_CODE_TMPDIR`; short unique `/tmp/fb...` work directories avoid long temporary paths. Scratch files and Python bytecode are ignored by the synthetic Git repository.

The earlier CSV task also left blank-record handling ambiguous. The corrected contract distinguishes blank physical lines outside quoted fields from rows containing quotes or delimiters: ` , , ` must be validated and rejected, rather than ignored. The original CSV diagnostic is excluded from comparison with the corrected case. Retained case hashes prevent regrading a saved product against changed fixtures or acceptance tests.

Regrading remains an offline inspection of retained products. It records `snapshot_quality` independently of first-pass and final-delivery quality, preserves incomplete status and unknown delivery times, and retains observed cumulative usage as lower bounds. It does not launch another model or invent workflow completion.

An isolated Context Mode RPC smoke check succeeded with 11 exposed tools, including Python `ctx_execute` returning `CTX_READY`, while personal Claude settings remained unchanged. This checks the adapted MCP transport and runtime, not comparative product quality or token savings. The adaptation is pinned to Context Mode `1.0.169` and currently requires macOS, prepared dependencies, and a working SQLite/FTS5 runtime. MCP startup and hooks need their own confined configuration/storage; changing the main Claude configuration would disrupt its normal authentication. This preparation is distinct from the dependency-free Python benchmark products. No Context Mode comparison result is claimed here.

Correction attempts at `/private/tmp/factory-comparison-corrected-20261012` and `/private/tmp/factory-comparison-finalpilot-20261012` exposed further automation defects: fresh agents refused forwarded simulated sign-off, native JSON-schema enforcement interrupted agents waiting on reviewers, and provisional plain-text root results were mistaken for final protocol replies. Those runs were stopped and are excluded. The controller now requests a single JSON object directly, accepts only a protocol root result as successful turn completion, and records the copied Factory manual-invocation and synthetic-operator adaptations.

The benchmark measures trusted product tests, initial versus repaired delivery, cumulative token classes, wall time, and simulated question counts. Manual human follow-up remains `null`: a controller echoing recommended answers does not measure human effort, review difficulty, or time spent correcting an unsuitable recommendation. Technical measurement validity and confirmed workflow adherence are separate fields. Blind source review and trajectory review are still required before claiming a full workflow comparison. One repeat on three small fixtures cannot establish whether a roughly 15% token premium buys a worthwhile reduction in real follow-up work.

Strict full-workflow equivalence is therefore unconfirmed; `comparative_valid` remains false for both arms, while technical `measurement_valid` is true.

A direct source probe found an additional compatibility difference outside the trusted tests: Superpowers preserves the original `splitlines()` record separator `\x85`; Factory raises `ValueError`. Factory's own reviews found that regression but the scripted operator accepted its recommended deferral. Thus equal acceptance scores do not establish equivalent quality, and simulated sign-off cannot prove less human follow-up.

For these observed adapted paths, Factory used 7.4 times the tokens and 5.7 times the time, with no measured quality gain. This supports Superpowers for this small CSV task, not a global switching decision.
