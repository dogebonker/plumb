# First local contract trial

The shared-contract worker passed all mechanical gates on its first attempt.
Opus rejected guessed publication-setting aliases and a homepage canonical
inherited by 404 responses. The one permitted repair fixed those patterns but
selected a different setting name because the exact name was absent from its
contract prose. The public-mode HTTP test then failed and the retry limit stopped
the run. No feature slice started and nothing merged or deployed.

the raw receipts and original source snapshots are unavailable for re-audit.
The [benchmark report](../../research/real-pr-benchmark-2026-10-19.md) carries the
same availability limitation. No benchmark inference was rerun.

The recovered shared-contract checkpoint passes production HTTP, types, lint,
architecture, scope and compiler export gates, including added 404 metadata
checks. Original frozen pilot inputs were recovered byte-for-byte. Three owned
files were recovered from original tool outputs; the content module and CSS were
reconstructed. The [recovery proposal](amendments/publication-recovery/README.md)
keeps architecture, ownership and public interfaces, declares the exact setting,
and allocates one bounded verification/review pass within the original total
feature ceiling. New evidence is stored outside `.tmp`.

Full end-to-end swarm execution, final merge, production deployment, Pond retro
writes and a same-feature legacy Factory cost control have not run.
